## 🌟 Key Features / قابلیت‌های کلیدی

### English
- High-speed camera barcode scanner
- Generator for QR, Aztec, DataMatrix, Code128
- Export & share as high-res image
- Scan history with search & filter

### فارسی
- اسکن فوق سریع با دوربین و پردازش زنده
- ساخت انواع کدهای QR، بارکد، Code128 و ...
- ذخیره در گالری و اشتراک‌گذاری با کیفیت بالا
- تاریخچه کامل اسکن‌ها و خروجی

## 🚀 Getting Started / راه‌اندازی پروژه

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK
- Android Studio / VS Code with Flutter extension

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pxf0rge/qr-barcode-scanner-generator.git
   cd qr-barcode-scanner-generator
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
